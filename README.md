## 🛠️ TECHNOLOGY STACK

<div align="center">

<img src="https://skillicons.dev/icons?i=html,css,sass,bootstrap,js,jquery" alt="HTML, CSS, Sass, Bootstrap, JavaScript, and jQuery" />

</div>

| TECHNOLOGY | PURPOSE |
|:---|:---|
| HTML5 | Semantic structure |
| CSS3 | Layout and visual styling |
| Sass (SCSS) | Reusable styles, variables, and mixins |
| Bootstrap | Responsive layouts and UI components |
| JavaScript | Interactive functionality |
| jQuery | DOM manipulation and event handling |
| Local Storage | Client-side data persistence |
| Font Awesome | Interface icons |
| SweetAlert2 | Interactive alerts |
| Owl Carousel | Carousel components |
| WOW.js | Scroll-triggered animations |

---

## 💡 DEVELOPMENT HIGHLIGHTS

**Reusable Styling** — Sass variables and mixins help maintain consistent design patterns.

**Interactive Functionality** — JavaScript and jQuery support dynamic interfaces and user interactions.

**Persistent Selections** — Local Storage preserves supported data between visits.

**Responsive Design** — Bootstrap and custom styling adapt the layout to different screen sizes.

## 🚀 GETTING STARTED

**01 — Clone the repository**

```bash
git clone https://github.com/basmla-mohamed/Cartella.git
```

**02 — Open the project folder**

```bash
cd Cartella
```

**03 — Launch the website**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
